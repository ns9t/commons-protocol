# A Commons Protocol

A founding design philosophy for a globally distributed, politically neutral consensus protocol — infrastructure for making humanity's expressed conscience visible, verifiable, and permanent.

This is a working document, not a finished product. It is versioned, open to improvement, and belongs to no one.

---

## What this is

This repository is the canonical home of the founding document for the Commons Protocol project. It contains the design philosophy, core principles, and open questions that any implementation of this idea must engage with.

It is not code. It is not an organisation. It is a seed.

---

## How to engage

**Read** the founding document: [`founding-document.md`](./founding-document.md)

**Propose improvements** via a GitHub Issue — argue with any section, suggest clearer language, identify gaps in the design, or point to relevant prior art not yet acknowledged.

**Translate** the document into another language and submit it as a pull request. Translations are among the most valuable contributions this project can receive.

**Build** an implementation that honours the founding principles. If you do, open an Issue to register it — this repository will maintain a list of known implementations so they remain connected to the canonical trunk.

**Cite or share** this document freely under the terms of the licence below.

To contact the stewardship: commonsprotocol@proton.me

---

## What not to do

Do not fork this document to produce a version that removes or modifies the founding principles. The principles are not features — they are the thing itself. An implementation that removes them is a different project and should be named accordingly.

Do not attach this document or the project name to any commercial enterprise. The signal must remain unmonetised. This is non-negotiable and is enforceable under the licence terms.

---

## Versioning

The document is versioned. The version history in this repository is the authoritative record of how and why the document has evolved. Significant changes will be noted in commit messages. Proposed changes to the founding principles themselves require open discussion via Issues before incorporation.

Current version: **0.7 — working draft — not for publication**
